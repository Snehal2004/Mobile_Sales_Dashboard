# 📱 Mobile Sales Dashboard | Power BI Project

## 📌 Project Overview

The **Mobile Sales Dashboard** is an interactive data analytics project developed using Microsoft Power BI to analyze mobile sales transactions and generate meaningful business insights. The dashboard presents key performance indicators (KPIs), sales trends, customer ratings, payment preferences, and brand performance through interactive visualizations.

The goal of this project is to transform raw sales data into an easy-to-understand dashboard that supports data-driven decision-making.

## 🎯 Project Objectives

- Analyze total sales and units sold.
- Track monthly sales quantity trends.
- Compare sales performance across mobile brands and models.
- Understand customer ratings and payment method preferences.
- Explore city-wise sales distribution.
- Analyze sales patterns across days of the week.
- Provide interactive filtering for detailed analysis.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Microsoft Excel** — Dataset storage and data preparation
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and KPI calculations

## 📂 Dataset Information

The dataset contains mobile sales transaction records with the following columns:

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Day | Day of the transaction |
| Month | Month of the transaction |
| Year | Year of the transaction |
| Day Name | Day of the week |
| Brand | Mobile brand |
| Units Sold | Number of mobile units sold |
| Price Per Unit | Price of each mobile unit |
| Customer Name | Customer name |
| Customer Age | Customer's age |
| City | City where the transaction occurred |
| Payment Method | Method used for payment |
| Customer Ratings | Customer rating for the purchase |
| Mobile Model | Mobile phone model |

## 📊 Dashboard Features

- **KPI Cards:** Quick overview of total sales, customer count, transaction count, and other key metrics.
- **Sales by City:** Geographic visualization of sales distribution across cities.
- **Monthly Quantity Trend:** Tracks changes in the number of units sold each month.
- **Customer Ratings:** Displays the distribution of customer ratings.
- **Payment Method Analysis:** Compares UPI, debit card, cash, and credit card transactions.
- **Brand Performance:** Compares total sales, quantity sold, and transactions across brands.
- **Sales by Mobile Model:** Identifies models contributing to total sales.
- **Sales by Day Name:** Highlights sales patterns across different weekdays.
- **Interactive Filters:** Enables analysis by mobile model, payment method, brand, day name, and month.
